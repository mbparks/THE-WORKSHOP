# THE WORKSHOP v9.0.4 — Crew Studio Redesign

Crew Studio has been rebuilt as a compact operations workspace with a clearer hierarchy, full-precision map controls, easier member-role management, ZIP coverage management, and grouped Crew actions.

## Highlights

- Crew identity + status dashboard at the top.
- Dedicated map-location workspace using the starred ZIP as the safe default.
- Latitude/longitude displayed in full 14-decimal format.
- Cleaner member cards with role badges and compact promotion/demotion controls.
- ZIP coverage shown as clear regional chips with the anchor ZIP emphasized.
- Meetups, Sessions, and Announcements grouped under Quick Actions.
- Responsive layout designed for desktop and mobile Crew administration.
