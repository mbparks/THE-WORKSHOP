- only the Project owner can mark another maker's response as useful;

- optional outcome notes remain attached to the original Project conversation;
- useful marks create one restrained, action-worthy notification;
- question answer marks notify the contributing maker;
- Make a Variation invitations can begin as Bench Handshakes and become linked personal Projects;
- every Maker Variation preserves source attribution, adaptation intent, and a starter Notebook entry;
- completed variations return a concise outcome to the source Project;
- source Projects collect visible variations in completed-first, never-ranked order;
- private variations never leak through source Projects or Bench Handshakes;
- the browser can mark a response, start a variation, complete it, and see it returned to the source without uncaught runtime errors;
