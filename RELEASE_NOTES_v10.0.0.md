# THE WORKSHOP v10.0.0 — Make Together

v10.0.0 turns the interaction features built across v9 into one coherent way to make with other people.

## One participation path

Make Together presents a practical sequence:

1. A maker opens a Project Bench and names the help that would matter.
2. Another maker offers a specific Bench Handshake.
3. The makers can use an Open Bench Hour when a real time is useful.
4. What changed stays attached to the Project as a Useful Response or Maker Variation outcome.

The hub filters open work by Bench Hours, feedback, practical help, testing, collaboration, tools or materials, and variations. Open Projects remain in recent-update order. Bench Hours remain soonest-first.

## My Shared Work

Signed-in members receive a private action queue that brings together:

- incoming Bench Hour requests and Handshakes that need a reply;
- their pending requests and offers;
- confirmed Bench Hours;
- accepted-only connection details.

The queue is calculated for the current member and is never included in anonymous responses. Project visibility and member blocking remain enforced on the server.

## Outcomes, not engagement metrics

What Shared Work Changed surfaces completed Maker Variations and Useful Responses already documented on visible Projects. It creates no separate post, feed, reputation system, or scoreboard.

v10.0.0 adds no public request counts, attendance totals, likes, follower ranking, popularity score, streak, opaque recommendation order, artificial urgency, or infinite scroll.
