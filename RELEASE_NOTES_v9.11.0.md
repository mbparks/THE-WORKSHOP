# THE WORKSHOP v9.11.0 — Useful Responses and Maker Variations

v9.11.0 makes participation leave a clearer, more durable trace on the work itself.

## Record what proved useful

Project owners can mark another maker's Project Talk contribution with one practical outcome:

- **Changed the Build** — it changed a decision, design, material, method, or next step;
- **Prevented a Problem** — it caught a risk, mistake, failure mode, or wasted effort;
- **Useful Direction** — it supplied a concrete test, reference, or way forward.

An optional note records what changed beside the original response. The contributing maker receives one restrained notification when a new mark is applied. No response total, score, reputation point, or popularity ranking is created.

Question-answer marks now also notify the contributor, reject missing answers cleanly, and recalculate the question's solved state from the actual marked answers.

## Turn an invitation into a Maker Variation

Projects with a **Make a Variation** Open Bench invitation now offer a direct path into a linked derivative Project. A variation can also begin from a variation-specific Bench Handshake.

Each variation preserves:

- the source Project and maker;
- what the new maker intends to change;
- its own visibility and project record;
- a concise outcome when **Show What You Built** returns the result.

Source Projects collect every variation the current viewer is allowed to see. Completed variations appear first, followed by active work in recent-update order. Private variations remain private even from the source Project owner.

The release adds no new top-level module, response counters, public scores, rankings, streaks, recommendation feed, or artificial urgency.
