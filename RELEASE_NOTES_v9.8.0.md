# THE WORKSHOP v9.8.0 — Open Bench Signals

v9.8.0 gives makers a clear, project-centered way to say how another person can join the work right now.

## Open a Bench

Project owners can choose one or more bounded invitations:

- Feedback Welcome
- Need a Hand
- Looking for Tester
- Open to Collaborator
- Need a Tool or Material
- Make a Variation

An optional request adds the practical detail: what to inspect, test, bring, lend, or help make. Removing every invitation closes the Open Bench without deleting any project history.

## Find useful ways to participate

- Open Bench signals appear on project cards and in a dedicated project-page callout.
- Home and Builds surface recently updated Open Benches.
- Public invitations remain visible without an account whenever the underlying project is public.
- Discovery is chronological, not popularity-ranked.

## Respond where the work lives

A response is added to the existing project discussion with its invitation context. This keeps the offer, question, and resulting conversation attached to the Project instead of creating a separate social feed.

The release adds no likes, response totals, public follower metrics, leaderboards, streaks, behavioral tracking, or algorithmic ranking.
