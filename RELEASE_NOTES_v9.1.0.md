# THE WORKSHOP v9.1.0 — Build Fit & Maker Variations

This release incorporates the strongest project-discovery and personalization ideas from the MakerMind review into THE WORKSHOP's existing modules. No new primary module is introduced.

## Builds

- **Build Fit** compares a visible project's stated tools and disciplines with the signed-in member's Bench tools, skills, and Want to Learn.
- Fit states are practical context—**Ready Now**, **Good Fit**, **Stretch Build**, or **Need Tool**—not rankings, scores, XP, or engagement mechanics.
- **Recommended for My Bench** appears in Builds and Home for signed-in members.
- **Make It Yours** creates a linked personal version of another visible project while preserving source attribution and starting a Notebook entry for the planned adaptations.

## My Bench

- **Next Stretch Build** surfaces a project that intersects with something the member has explicitly said they want to learn.

## Project + Notebook

- **Guided Build** adds an optional Prepare → Build → Check → Reflect working aid based on the project's real tools, materials, and Notebook evidence.
- Guided Build progress is local and deliberately non-gamified; the Notebook remains the durable record.
- **Ask with Project Context** can prefill Help + Critique with project stage, tools, materials, the latest Notebook entry, and project file references. Everything remains editable before publishing.
- **Show What You Built** marks a derivative project complete and can add a final Result note, returning the work to its originating project/community-build context.

## Community Builds

- Participant work is presented as **Maker Variations** rather than ranked responses.
- Completed variations are surfaced first while preserving all visible work.

## Shop Manual

Resources can now document:

- curator;
- built/tested by;
- difficulty;
- estimated time;
- required/useful tools;
- materials;
- Workshop projects that used or tested the resource.

## Saved

Saved build-oriented items now surface Build Fit and materials-to-check context so Saved acts more like a useful shelf than a passive bookmark list.

## Philosophy

This release intentionally does not add quotas, badges, points, Hammers, leaderboards, or a recommendation feed designed to maximize engagement. Recommendations derive only from explicit maker context already present on My Bench.
