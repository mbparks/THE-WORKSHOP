# THE WORKSHOP v9.5.0 — Collaboration Layer

Phase 2 adds practical collaboration without adding a generic social layer. Project owners can invite makers by @callsign into explicit roles; Project pages visibly credit the owner and collaborators. People now surfaces reciprocal Skill Exchange matches from member-declared Can Help With and Want to Learn fields. Help + Critique can route requests toward makers whose declared skills overlap the problem. Community Builds can form small opt-in teams that members can join or leave.

Internal IDs remain authoritative, profiles and project visibility remain enforced, and all collaboration notifications use the existing restrained notification system.
